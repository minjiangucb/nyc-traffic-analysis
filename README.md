# 🚗 NYC Traffic Accident Analysis

Interactive dashboard analyzing NYC traffic accidents with EDA, statistical testing, and ML-based prediction.

## 📊 Key Insights
- **Brooklyn** has the highest crash volume
- **Driver Inattention/Distraction** is the top preventable cause
- **Rush hours** show peak crash volume
- **COVID-19** caused a 40% temporary drop

## 🔮 Predictive Model
- RandomForest Regressor with ±12 crashes/day MAE

## 🛠️ Tech Stack
- Python, Pandas, Scikit-learn
- Streamlit, Matplotlib, Seaborn
- Folium, Statsmodels
